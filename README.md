# Сайт книги «Как стать носителем иностранных языков за 4 месяца»

Автор: Maximov Alexander.
Стиль: строго чёрно-белый, светлая и тёмная темы, только HTML, CSS и vanilla JavaScript.

## Состав проекта

- `index.html` - главная страница (русская версия);
- `assets/css/style.css` - оформление и обе темы;
- `assets/js/langs.js` - реестр языков и определение языка посетителя;
- `assets/js/app.js` - плитки глав, переключение темы, счётчик глав;
- `assets/js/data.ru.js` - текст книги (создаётся автоматически из Ru.docx);
- `assets/img/chart.png` - иллюстрация из книги (извлекается автоматически);
- `assets/img/favicon.svg` - иконка сайта;
- `tools/build-book.mjs` - сборка содержимого книги из Ru.docx;
- `tools/serve.mjs` - локальный сервер для просмотра;
- `Ru.docx` - исходная книга.

## Как обновить текст книги

1. Отредактируйте `Ru.docx`:
   - названия глав должны иметь стиль «Заголовок 1»;
   - ключевые предложения выделяйте подсветкой текста (маркером) в Word - именно они попадут в превью плитки.
2. Запустите:

   ```
   node tools/build-book.mjs
   ```

3. Обновите страницу в браузере.

Правила сборки:

- глава начинается с абзаца стиля «Заголовок 1»;
- превью плитки - все предложения главы, содержащие подсветку; в развёрнутой главе они тоже подсвечены;
- если в заголовке несколько предложений, первое становится названием плитки, остальные - первым абзацем главы;
- глава «Зачем учиться писать на иностранном языке?» восстанавливается автоматически: в книге у неё нет заголовка в тексте;
- пустые заголовки пропускаются, глава без текста не создаётся. Сейчас так пропускается заголовок «Алгоритмы для тренировки словарного запаса...» - добавьте под ним текст, и плитка появится;
- картинка из книги (график) переносится автоматически.

## Локальный просмотр

```
node tools/serve.mjs
```

Затем откройте http://localhost:8080

Можно открыть и просто `index.html` двойным щелчком: сайт работает и без сервера.

## Что заменить перед публикацией (атрибут data-todo)

Найдите в `index.html` элементы с атрибутом `data-todo`:

- `data-todo="app-android"` - ссылка на Google Play;
- `data-todo="app-chrome"` - ссылка на Chrome Web Store;
- `data-todo="donate-bmc"` - Buy Me a Coffee;
- `data-todo="donate-patreon"` - Patreon;
- `data-todo="social-telegram"`, `social-whatsapp`, `social-facebook`, `social-instagram`, `social-vk`, `social-linkedin`, `social-github` - ссылки на соцсети.

Замените заглушку вида

```html
<span class="btn btn--disabled" aria-disabled="true" data-todo="app-android">Google Play</span>
```

на настоящую ссылку

```html
<a class="btn" href="https://play.google.com/store/apps/details?id=...">Google Play</a>
```

и уберите тег «Скоро», когда приложение выйдет.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub (без README).
2. В папке сайта выполните (замените ПОЛЬЗОВАТЕЛЬ и РЕПОЗИТОРИЙ):

   ```
   git init
   git add .
   git commit -m "Сайт книги"
   git branch -M main
   git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

3. В GitHub откройте Settings -> Pages, в разделе Build and deployment выберите «Deploy from a branch», ветку `main` и папку `/ (root)`, сохраните.
4. Через минуту-две сайт будет доступен по адресу `https://ПОЛЬЗОВАТЕЛЬ.github.io/РЕПОЗИТОРИЙ/`.
5. Свой домен подключается там же, в разделе Pages (Custom domain).

## Как добавить язык

1. Создайте папку языка, например `en/`, и положите туда копию `index.html`:
   - в теге `<html>` замените `lang="ru"` на `lang="en"`;
   - подключите `assets/js/data.en.js` вместо `data.ru.js` (пути станут `../assets/...`).
2. Создайте `assets/js/data.en.js` с той же структурой, что у `data.ru.js` (перевод текста книги).
3. Добавьте язык в массив `LANGS` в файле `assets/js/langs.js`:

   ```js
   { code: 'en', name: 'English', dir: 'en/' }
   ```

После этого скрипт сам направит посетителя с английским браузером на `/en/`, а переключатель языка появится в шапке и подвале.

## Как работает определение языка посетителя

Приоритет выбора языка:

1. параметр адреса `lang` (например, добавить `?lang=en` к адресу страницы);
2. сохранённый выбор посетителя (localStorage);
3. языки браузера (`navigator.languages`).

Если подходящего перевода нет, посетитель остаётся на русской версии. Поскольку GitHub Pages - статический хостинг, перенаправление выполняет JavaScript. Если позже понадобится серверное перенаправление по заголовку `Accept-Language` (до загрузки страницы), это делается на Netlify или Cloudflare без изменений в коде сайта.
